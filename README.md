# fastfetch for yandex.station 2
fastfetch for jailbroken Yandex Station (2-gen only)

## Build for Specific Station 2 Linux based OS

Here's some details:
* ARMv7l (32-bit ARM hard-float)
* glibc 2.30
* Linux version 4.9.68
